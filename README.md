## data processing and streamlit dashboard for report 
### Use this pipeline if your goal is to add woreda to the data_base files 

#### step by step guide to follow 
    1 pip install -r requirment.txt 
    2 source .venv/bin/activate
    2 put all the files in the input folder 
    3 python full_pipeline.py 
    4 the output (the data_base files with woreda column) will be found inside woreda_added


#### to the start the dashboard
    run -------->  streamlit run app/app.py
